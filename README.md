# Beginner-friendly Python example

This repository now includes a tiny command-line Python program in `/home/runner/work/Github_Copilot/Github_Copilot/simple_cli.py`.

It prints a greeting and adds two whole numbers using only the Python standard library.

## Run it

```bash
python3 simple_cli.py --name Alice 2 3
```

Expected output:

```text
Hello, Alice! 2 + 3 = 5
```

You can also omit `--name`:

```bash
python3 simple_cli.py 4 6
```
